# HambakTech Architecture

## Overview

HambakTech is a Next.js full-stack platform using:

- Next.js App Router
- React
- TypeScript
- Prisma ORM
- PostgreSQL
- NextAuth
- Tailwind CSS

The application is organized around reusable components, application routes, services, actions, shared utilities and database models.
